# Gemini AI and Chrome extension integration

`AIRecommendations.tsx` sends a POST to `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${import.meta.env.VITE_GEMINI_API_KEY}` with `Content-Type: application/json` and `{contents:[{parts:[{text: prompt}]}]}`. Its prompt template is the literal Spanish source string in `src/components/AIRecommendations.tsx`: it begins `Eres un analista experto en marketing digital y growth hacking, especializado en optimización de perfiles profesionales en LinkedIn. Tu tarea es analizar exhaustivamente las métricas de rendimiento de un perfil de LinkedIn y proporcionar recomendaciones estratégicas personalizadas basadas en datos.`; interpolates labeled JSON for `generalMetrics`, `postTypeAnalysis`, `categoryAnalysis`, `timeAnalysis`, `contentLength`, `trends`, and `lastPosts`; then instructs: `Basándote en estos datos, genera un análisis completo` with executive summary, detailed profile/type/temporal/length/trend analysis, and recommendations for `Tipos de contenido`, `Mejores horarios`, `Longitud óptima`, `Frecuencia recomendada`, and `Estrategias de engagement`. It further requires data-backed, practical, personalized, measurable recommendations; examples and prioritized impact; current LinkedIn context; exact tags `<Tipos de contenido></Tipos de contenido>`, `<Mejores horarios></Mejores horarios>`, `<Longitud óptima></Longitud óptima>`, `<Frecuencia recomendada></Frecuencia recomendada>`, `<Estrategias de engagement></Estrategias de engagement>`; bullet-point HTML; second-person `tú`; concrete examples; and no generic “analiza el rendimiento individual” advice. This is the complete stable prompt contract; the full copy is source-owned because product wording is lengthy and mutable.

The response is read once as JSON, then `candidates[0].content.parts[0].text` is extracted. If fetch/JSON throws, catch logs `Error al analizar los datos:` and sets `err.message || 'Error al analizar el perfil'`; if candidates/text are absent it logs `Respuesta vacía o inválida` and does not save. A response without expected tags produces empty fields but can still be saved. Save calls `/api/recommendations`; on success it records `profile_analysis` with recommendation ID and metric keys, then updates UI. Initial loading catches latest/profile/usage failures to null/console paths. No retry or key prevalidation exists.

`PostsTable.tsx` sends the same REST model and JSON headers with ten `{url,text}` records, asks for <=15 broad categories and JSON, requires a ```json fenced block, retries three attempts and waits 60 seconds on 429, then calls `/api/posts/:url/category` separately. Non-OK responses, missing text, or malformed fences can leave earlier writes committed. `Planner/PostEditor.tsx` uses `@google/generative-ai`, `gemini-1.5-pro`, and browser `VITE_GEMINI_API_KEY` for text optimization with no equivalent retry. Its image handler only logs prompt/style; `src/lib/ai.ts` exports an unused `gemini-1.5-pro` helper.

The browser URL exposes `VITE_GEMINI_API_KEY`; it is not a server secret. Recommendation persistence uses required indexed `user_id` ObjectId ref, default-empty strings `tipos_de_contenido`, `mejores_horarios`, `longitud_optima`, `frecuencia_recomendada`, `estrategias_de_engagement`, and `date_generated` defaulting to `Date.now` (plus timestamps). Route save sets caller ID/date; database failures reach the shared error handler; latest filters caller ID and sorts date descending.

`extensionCommunication.ts` checks `chrome`, `chrome.runtime`, and `sendMessage`; absent APIs no-op. ID is `beicaapgmnneiipgjekoapgjehjdajjn`. `CHECK_SYNC` sends `{type:'CHECK_SYNC'}` and expects `response.synced`; false/missing response sets `sessionSent=false` and immediately calls `sendAuthToExtension`. `AUTH_SUCCESS` sends `{type:'AUTH_SUCCESS',session:{access_token,refresh_token,user}}`. `App.tsx` triggers on session and pathname changes. Rejected messaging is caught/logged; no timer or automatic retry exists beyond another trigger, and failures do not block the app.
